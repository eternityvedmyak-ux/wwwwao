# 🚀 Инструкция по настройке Автодоната (Minecraft)

Этот проект представляет собой современный автодонат-сайт для серверов Minecraft с поддержкой мультисерверности, зимней/летней тем оформления, интерактивным фоном, встроенной базой знаний (WIKI) и защищенным тестовым режимом.
---

## 🛠️ Шаг 1: Основные настройки сайта и SEO
Откройте [config.php](autodonate/config.php) и укажите основные данные вашего проекта в первой секции:
* **`site_name`** — название вашего проекта (отображается во вкладке браузера и в шапке сайта).
* **`server_ip`** — IP-адрес вашего сервера (отображается игрокам, копируется при клике в один клик).
* **`description`** и **`keywords`** — описание и ключевые слова для индексации сайта поисковиками (SEO).

---

## 🎨 Шаг 2: Визуальное оформление и темы
Настройте внешний вид сайта:
* **`theme`** — тема оформления: 
  * `"winter"` — новогодняя тема со снегопадом и гирляндами.
  * `"summer"` — строгий премиальный стиль без зимних элементов.
* **`hero_character`** — никнейм игрока, чей 3D-скин будет красоваться на главном баннере. Для отключения оставьте пустым: `""`.
* **`bg_items_enabled`** — включить (`true`) или выключить (`false`) летающие 3D-предметы на фоне.
* **`colors`** — настройте цвета бренда в формате HEX:
  * `accent` — цвет свечения, кнопок и активных элементов.
  * `bg_main` — основной глубокий фон.
  * `bg_card` — цвет фона плашек и карточек.

---

## 📦 Шаг 3: Настройка базы данных MySQL
1. Создайте базу данных в панели управления (например, через phpMyAdmin).
2. Импортируйте структуру таблиц из файла [schema.sql](htdocs/autodonate/schema.sql).
3. В блоке `"db"` укажите ваши доступы:
   ```php
   "db" => [
       "host" => "localhost",    // Адрес сервера БД
       "user" => "root",         // Пользователь БД
       "password" => "пароль",   // Пароль от БД
       "db" => "autodonate",     // Имя вашей базы данных
   ]
   ```

## 🔒 Шаг 4: Безопасность и тестовый режим
Проект оснащен встроенным тестовым режимом для проверки выдачи доната без реальной оплаты.

> [!WARNING]
> Обязательно измените ключ `"admin_test_key"` по умолчанию на сложный длинный пароль, чтобы злоумышленники не смогли получить бесплатный донат.

### Как совершить тестовый платеж:
Перейдите по ссылке в браузере:
`http://ваш-сайт.ру/library/makePayment.php?username=Ник&good=ID_товара&payment_system=test&test_key=ВАШ_КЛЮЧ&server=grief1`

* `username` — ник игрока, которому выдается донат.
* `good` — ID товара из каталога (например, `voin` или `knight`).
* `test_key` — ваш секретный ключ из `config.php`.
* `server` — ID сервера (например, `grief1` или `grief2`).

## 💳 Шаг 5: Платежные системы
Вы можете быстро отключать и подключать любые платежные шлюзы, меняя `true` на `false` в массиве `"payment_systems"`:
```php
"payment_systems" => [
    "unitpay" => true,  // Включен
    "enot" => false,    // Отключен (скрыт с сайта)
    "ykassa" => true,
    "platega" => true,
]
```
Ниже укажите соответствующие API-ключи для используемых платежных шлюзов в блоках `"unitpay"`, `"ykassa"`, `"platega"` и `"enot"`.

## 🎟️ Шаг 6: Промокоды и таймер скидок
* В блоке `"promo"` настраивается праздничный таймер распродажи: включение/отключение (`enabled`), текст над таймером (`text`) и дата окончания акции (`end_date`).
* В массиве `"promo_codes"` укажите промокоды и размер предоставляемой скидки в процентах:
  ```php
  "promo_codes" => [
      "NEWYEAR" => 20, // Промокод дает скидку 20%
      "STORM" => 15,   // Скидка 15%
  ]
  ```

---

## 📚 Шаг 7: Статистика и База Знаний (WIKI)
* В блоке `"stats"` настройте счетчики игроков и аптайма, отображаемые на главной странице.
* В блоке `"super_products"` перечислите привилегии, с которых нельзя доплатить на более дешевые (например, админские группы).
* В блоке `"wiki"` настраивается страница [wiki.php](autodonate/wiki.php):
  * `"steps"` — пошаговая инструкция «Как купить донат» (номера, заголовки, тексты).
  * `"privileges"` — описание возможностей групп (верстак, fly, kit-наборы).

## 🖥️ Шаг 8: Мультисерверность и RCON выдача
Сайт поддерживает неограниченное число серверов. Игроки могут выбирать нужный сервер во вкладках на главной странице.

> [!TIP]
> При использовании одного IP-адреса для нескольких серверов, укажите для каждого сервера уникальный RCON-порт в настройках `server.properties` Minecraft.

Для каждого сервера в массиве `$config['servers']` настраивается индивидуальный блок:
```php
"grief1" => [
    "title" => "Гриф #1", // Название вкладки на сайте
    "rcon" => [
        "ip" => "127.0.0.1",       // IP сервера
        "port" => "7777",          // RCON порт сервера 1
        "password" => "пароль_rcon" // RCON пароль сервера 1
    ],
    "categories" => [
        // Индивидуальные категории товаров и цены для данного сервера
    ]
]
```

### Настройка RCON в Minecraft (`server.properties`):
На каждом игровом сервере включите RCON и настройте порты:
* **Сервер #1**: `enable-rcon=true`, `rcon.port=7777`, `rcon.password=пароль_rcon`
* **Сервер #2**: `enable-rcon=true`, `rcon.port=7778`, `rcon.password=пароль_rcon2`
